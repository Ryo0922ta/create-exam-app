## 1. アプリの概要

本アプリには **2つの使い方** があります。

| 機能 | 入口 | 向いている用途 |
|------|------|----------------|
| **A. CSVから試験用紙を作る** | トップページ `/` | 4択・単語・自由記述の問題を CSV から一括生成 |
| **B. 解答用紙エディタ** | `/editor` | 定期考査用の解答用紙を自由にレイアウト |

どちらもブラウザ上で完結し、サーバーにデータを送信しません。

# 機能A: CSVから試験用紙を作る

## 2. 利用の流れ

1. CSVファイルを選択するか、アップロード領域へドラッグ&ドロップします。
2. 表示されたレイアウト設定で、問題形式ごとの表示件数、横、縦を指定します。
3. `プレビューを表示` を選択し、問題用紙・解答用紙を確認します。
4. `PDFをダウンロード` を選択します。

PDFには問題用紙と解答用紙がこの順に1ファイルへ含まれます。

## 3. 対応ファイル

- 形式: CSVファイル
- 文字コード: UTF-8、Shift-JIS
- 必須ヘッダー: `問題番号`、`問題文`
- 任意ヘッダー: `問題形式`、`選択肢1`〜`選択肢4`、`文字数制限`

ヘッダーの前後にある空白は自動的に除去されます。

## 4. CSVの書式

### 4.1 共通項目

| ヘッダー | 必須 | 内容 |
| -------- | ---- | ---- |
| `問題番号` | 必須 | 数値。CSV内の並び順を決めます。 |
| `問題形式` | 任意 | `4択`、`単語`、`自由記述` |
| `問題文` | 必須 | 出題する文章 |
| `選択肢1`〜`選択肢4` | 任意 | 4択問題の選択肢 |
| `文字数制限` | 任意 | 自由記述の上限文字数（正の整数） |

### 4.2 4択問題

```csv
問題番号,問題形式,問題文,選択肢1,選択肢2,選択肢3,選択肢4,文字数制限
1,4択,真核細胞でDNAの大部分を含む構造はどれか。,細胞膜,核,リボソーム,液胞,
```

### 4.3 単語回答

`語句`、`一問一答` も単語回答として扱われます。

```csv
2,単語,生物の体を構成する基本単位を何というか。,,,,,
```

### 4.4 自由記述

`記述`、`論述` も自由記述として扱われます。

```csv
3,自由記述,光合成と呼吸の関係を説明しなさい。,,,,,120
```

## 5. レイアウト設定

| 設定 | 内容 |
| ---- | ---- |
| 表示件数 | CSVから用紙に含める問題数 |
| 横 | 解答欄を横方向に並べる数 |
| 縦 | 解答欄を縦方向に並べる数 |

`横 × 縦 >= 表示件数` である必要があります。

## 6. 問題番号と表示順

CSVの `問題番号` を昇順に並べ、用紙上では `問1` から連番を付けます。問題用紙と解答用紙で同じ表示番号が使われます。

## 7. PDF出力（機能A）

- A4縦向き
- 問題用紙と解答用紙を1つのPDFへ結合
- 各用紙のページ番号は独立（例: 問題用紙 1/2、解答用紙 1/1）
- ダウンロード名: CSV名 + `-問題・解答用紙.pdf`

# 機能B: 解答用紙エディタ

## 8. エディタを開く

1. トップページ `/` のヘッダーから **「解答用紙エディタを開く」** をクリック
2. `/editor` が開き、B4横サイズのキャンバスが表示されます

## 9. ツールバー操作

### 大問・インポート

| ボタン | 操作 |
| ------ | ---- |
| **大問を作成・追加** | 新規大問ブロックを作成して canvas に配置 |
| **問題文から自動インポート** | 問題文テキストから小問記号を抽出し、小問複合枠を生成 |

### 基本パーツ

| ボタン | 操作 |
| ------ | ---- |
| **+ 考査見出し枠** | 考査タイトル行を追加（選択して右側サイドパネルからテキストやサイズを編集可能） |
| **+ 年組氏名欄** | 年・組・番・氏名欄を追加（選択して右側サイドパネルから各ラベルやサイズを編集可能） |
| **+ 観点別得点枠** | 知・技 / 思・判・表 / 合計の得点表を追加（選択して右側サイドパネルから観点名・配点注記・サイズを編集可能） |

### オブジェクト操作

| 操作 | 方法 |
| ---- | ---- |
| 移動 | オブジェクトをドラッグ |
| 編集 | 枠をクリック選択 → ツールバーの **プロパティ** を押して右側サイドパネルを開き、文字列・配点・幅・高さをリアルタイム編集（大問の横幅はスライダーまたは数値直接入力） |
| 複製 | 選択して **複製** ボタン |
| 削除 | 選択して **削除** ボタン、または Delete キー |

## 10. 表示設定

| 設定 | 説明 |
| ---- | ---- |
| **方眼グリッド** | 5mm 間隔の方眼を表示（余白ガイド 5mm 時の角マスと同サイズ） |
| **吸着(スナップ)** | ドラッグ時に方眼へ吸着 |
| **配置ガイド** | ドラッグ中に整列位置を rose 色の破線で表示 |
| **余白ガイド** | 上下（10–25mm）・外側（左端・右端、10–20mm）・折り目（中央折り目付近、10–20mm）を amber 色の点線で表示（PDF には含まれない） |
| **ズーム** | `-` / `+` / **画面に合わせる** で拡大縮小 |

## 11. 大問ブロックの4パターン

大問を作成・編集するモーダルで **解答枠パターン** を選びます。

### (1)(2) 小問複合枠

- **行数** / **列数** / **1行の高さ**
- **小問記号**（カンマ区切り）: `(1), (2), (3)` 等
- 「マス数分 (1)〜(N) を自動生成」ボタンあり

### 等分割グリッド

- **行数** / **列数** / **1行の高さ**
- ラベルなしの空マス目

### 丸数字区分

- **行数** / **列数** / **1行の高さ**
- ①②③… を行優先で配置（2行×5列 → ①〜⑤ / ⑥〜⑩）
- **「,」で区切る**: ON で全セルにカンマ表示
- **位置を自動調整**: 列数に応じてカンマ位置を自動計算
- 手動時: **カンマ位置（セル幅に対する比率 %）** で微調整

### 左右2分割枠

- **分割比率**: 50:50 / 30:70 / 70:30
- **枠の高さ**

### 共通項目

- **大問番号**、**観点区分**（例: ○・△・×）、**配点**（例: 各問1点/10点）
- モーダル下部にリアルタイム **プレビュー** が表示されます

## 12. 問題文から自動インポート

1. **問題文から自動インポート** をクリック
2. 問題文を貼り付け（`(1)`, `①`, `[1]` 等の記号を自動検出）
3. 行数・列数・大問番号・観点区分を確認
4. 適用 → 小問複合枠の大問ブロックが canvas に追加されます

## 13. 観点記号の一括置換

ヘッダー右側の **観点記号の一括置換** から、全大問ブロックの観点区分文字列を一括で置換できます（例: `○・△・×` → `知識・技能`）。

## 14. 出力（機能B）

| ボタン | 出力 |
| ------ | ---- |
| **PDFに保存 → B4横 (原寸1枚) PDF** | B4横1ページ PDF |
| **PDFに保存 → A4分割 (左面・右面2ページ) PDF** | A4縦2ページ（canvas 左右分割） |
| **Word形式 (.docx) で保存** | Word 文書 |

方眼・配置ガイド・選択枠は出力時に自動で除外されます。

## 15. その他

- **白紙に戻す**: canvas 上のすべてを削除（確認あり）
- レイアウトの **保存/読込機能はありません**。リロードすると初期状態に戻ります

---

## 16. エラーが表示された場合

### 機能A（CSV）

- ヘッダーに `問題番号` と `問題文` があるか
- 問題番号が数値か、問題文が空でないか
- レイアウト設定が `横 × 縦 >= 表示件数` を満たすか

### 機能B（エディタ）

- PDF/Word 生成中にブラウザのダウンロードがブロックされていないか
- 出力に時間がかかる場合は、そのまま待つ（処理中トーストが表示されます）
