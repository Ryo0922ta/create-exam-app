# 解答用紙作成アプリ 利用ガイド

## 1. アプリの概要

CSVファイルから問題を読み込み、問題用紙と解答用紙をプレビューしてPDFとしてダウンロードするアプリです。4択、単語回答、自由記述に対応しています。

## 2. 利用の流れ

1. CSVファイルを選択するか、アップロード領域へドラッグ&ドロップします。
2. 表示されたレイアウト設定で、問題形式ごとの表示件数、横、縦を指定します。
3. `プレビューを表示` を選択し、問題用紙・解答用紙を確認します。
4. `PDFをダウンロード` を選択します。

PDFには問題用紙と解答用紙がこの順に1ファイルへ含まれます。

## 3. 対応ファイル

- 形式: CSVファイル
- 文字コード: UTF-8、Shift-JIS
- 必須ヘッダー: `問題番号`、`問題文`
- 任意ヘッダー: `問題形式`、`選択肢1`、`選択肢2`、`選択肢3`、`選択肢4`、`文字数制限`

ヘッダーの前後にある空白は自動的に除去されます。

## 4. CSVの書式

### 4.1 共通項目

| ヘッダー              | 必須 | 内容                                                      |
| --------------------- | ---- | --------------------------------------------------------- |
| `問題番号`            | 必須 | 数値で入力します。CSV内の並び順を決めるために使用します。 |
| `問題形式`            | 任意 | `4択`、`単語`、`自由記述` のいずれかを入力します。        |
| `問題文`              | 必須 | 出題する文章を入力します。                                |
| `選択肢1` - `選択肢4` | 任意 | 4択問題の選択肢を入力します。                             |
| `文字数制限`          | 任意 | 自由記述問題の上限文字数を正の整数で入力します。          |

### 4.2 4択問題

`問題形式` に `4択` を入力し、`選択肢1` から `選択肢4` を入力します。選択肢が空欄の場合、プレビューとPDFには「（選択肢未設定）」と表示されます。

```csv
問題番号,問題形式,問題文,選択肢1,選択肢2,選択肢3,選択肢4,文字数制限
1,4択,真核細胞でDNAの大部分を含む構造はどれか。,細胞膜,核,リボソーム,液胞,
```

### 4.3 単語回答

`問題形式` に `単語` を入力します。`語句`、`一問一答` も単語回答として扱われます。

```csv
2,単語,生物の体を構成する基本単位を何というか。,,,,,
```

### 4.4 自由記述

`問題形式` に `自由記述` を入力します。`記述`、`論述` も自由記述として扱われます。文字数を制限する場合は `文字数制限` に正の整数を入力します。

```csv
3,自由記述,光合成と呼吸の関係を説明しなさい。,,,,,120
```

文字数制限を空欄にすると、上限なしの記述欄として扱われます。

## 5. レイアウト設定

問題形式ごとに次の値を指定します。

| 設定     | 内容                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 表示件数 | CSVから用紙に含める問題数です。CSV内の該当問題数を超えて指定できません。 |
| 横       | 解答欄を横方向に並べる数です。                                           |
| 縦       | 解答欄を縦方向に並べる数です。                                           |

すべての問題形式で、`横 x 縦` は表示件数以上である必要があります。

## 6. 問題番号と表示順

CSVの `問題番号` を昇順に並べ、用紙上では選択された問題だけに対して `問1` から連番を付けます。問題用紙と解答用紙では、同じ問題に同じ表示番号が使われます。

## 7. PDF出力

- A4縦向きで出力します。
- 問題用紙と解答用紙を1つのPDFへ結合します。
- 問題用紙と解答用紙のページ番号は別々に始まります。例: `問題用紙 1 / 2`、`解答用紙 1 / 1`。
- ダウンロード名は、CSV名に `-問題・解答用紙.pdf` を付けたものです。
- ブラウザの印刷機能を使用しないため、URL、日時、ブラウザのページタイトルはPDFに含まれません。

## 8. エラーが表示された場合

次を確認してください。

- CSVのヘッダーに `問題番号` と `問題文` があるか
- 問題番号が数値であるか
- 問題文が空欄でないか
- レイアウト設定が `横 x 縦 >= 表示件数` を満たすか
- PDF生成中に通信やブラウザのダウンロードが妨げられていないか
