## 1. アプリの概要

本アプリには **2つの使い方** があります。

| 機能 | 入口 | 向いている用途 |
|------|------|----------------|
| **A. CSVから試験用紙を作る** | トップページ `/` | 4択・単語・自由記述の問題を CSV から一括生成 |
| **B. 解答用紙エディタ** | `/editor` | 定期考査用の解答用紙を自由にレイアウト |

どちらもブラウザ上で完結し、サーバーにデータを送信しません。

# 機能A: CSVから試験用紙を作る

## 2. 利用の流れ

1. CSVファイルを選択するか、アップロード領域へドラッグ&ドロップします。
2. 表示されたレイアウト設定で、問題形式ごとの表示件数、横、縦を指定します。
3. `プレビューを表示` を選択し、問題用紙・解答用紙を確認します。
4. 必要に応じて問題用紙を編集し、**解答用紙に同期** します。
5. PDF対象を選び `PDFをダウンロード` を選択します。

PDFには問題用紙と解答用紙がこの順に1ファイルへ含まれます（対象選択により片方のみも可能）。

## 3. 対応ファイル

- 形式: CSVファイル
- 文字コード: UTF-8、Shift-JIS
- 必須ヘッダー: `問題番号`、`問題文`
- 任意ヘッダー: `問題形式`、`選択肢1`〜`選択肢4`、`文字数制限`

ヘッダーの前後にある空白は自動的に除去されます。

## 4. CSVの書式

### 4.1 共通項目

| ヘッダー | 必須 | 内容 |
| -------- | ---- | ---- |
| `問題番号` | 必須 | 数値。CSV内の並び順を決めます。 |
| `問題形式` | 任意 | `4択`、`単語`、`自由記述` |
| `問題文` | 必須 | 出題する文章 |
| `選択肢1`〜`選択肢4` | 任意 | 4択問題の選択肢 |
| `文字数制限` | 任意 | 自由記述の上限文字数（正の整数） |

### 4.2 4択問題

```csv
問題番号,問題形式,問題文,選択肢1,選択肢2,選択肢3,選択肢4,文字数制限
1,4択,真核細胞でDNAの大部分を含む構造はどれか。,細胞膜,核,リボソーム,液胞,
```

### 4.3 単語回答

`語句`、`一問一答` も単語回答として扱われます。

```csv
2,単語,生物の体を構成する基本単位を何というか。,,,,,
```

### 4.4 自由記述

`記述`、`論述` も自由記述として扱われます。

```csv
3,自由記述,光合成と呼吸の関係を説明しなさい。,,,,,120
```

## 5. レイアウト設定

| 設定 | 内容 |
| ---- | ---- |
| 表示件数 | CSVから用紙に含める問題数 |
| 横 | 解答欄を横方向に並べる数 |
| 縦 | 解答欄を縦方向に並べる数 |

`横 × 縦 >= 表示件数` である必要があります。

## 6. 問題番号と表示順

CSVの `問題番号` を昇順に並べ、用紙上では `問1` から連番を付けます。問題用紙と解答用紙で同じ表示番号が使われます。

## 7. プレビュー編集と同期

### 問題用紙の編集

- **問題用紙** タブで、各問題の文章や選択肢を直接編集できます。
- 編集後、ヘッダーに **「問題用紙: 編集あり」** バッジが表示されます。

### 解答用紙への同期

- 問題用紙を編集しただけでは解答用紙は自動更新されません。
- **「解答用紙に同期」** ボタンを押すと、編集内容が解答用紙プレビューに反映されます。
- 未同期時は **「解答用紙: 未同期」** バッジが表示されます。

### 編集の取り消し

- **「元に戻す」** — 問題用紙の編集をアップロード時の状態に戻します（解答用紙も同時に戻ります）。

### CSV再エクスポート

- **「CSVエクスポート」** — 編集後の問題データを CSV ファイルとしてダウンロードします。

## 8. PDF出力（機能A）

- A4縦向き
- ダウンロード対象を選択できます:
  - **全部（問題・解答用紙）** — 問題用紙と解答用紙を1つのPDFへ結合
  - **問題用紙のみ**
  - **解答用紙のみ** — 同期済みの内容が出力されます
- 各用紙のページ番号は独立（例: 問題用紙 1/2、解答用紙 1/1）
- ダウンロード名: CSV名 + `-問題・解答用紙.pdf`

# 機能B: 解答用紙エディタ

## 9. エディタを開く

1. トップページ `/` のヘッダーから **「解答用紙エディタを開く」** をクリック
2. `/editor` が開き、B4横サイズのキャンバスが表示されます

## 10. ツールバー操作

### 大問・インポート

| ボタン | 操作 |
| ------ | ---- |
| **大問を作成・追加** | 新規大問ブロックをモーダルで作成して canvas に配置 |
| **問題文から自動インポート** | 問題文テキストから小問記号を抽出し、小問複合枠を生成 |

### 基本パーツ

| ボタン | 操作 |
| ------ | ---- |
| **+ 考査見出し枠** | 考査タイトル行を追加 |
| **+ 年組氏名欄** | 年・組・番・氏名欄を追加 |
| **+ 観点別得点枠** | 知・技 / 思・判・表 / 合計の得点表を追加 |

### オブジェクト操作

| 操作 | 方法 |
| ---- | ---- |
| 移動 | オブジェクトをドラッグ |
| 新規大問作成 | **大問を作成・追加** → モーダルで設定 |
| 既存ブロック編集 | 枠をクリック選択 → ツールバーの **プロパティ** で右側サイドパネルを開く |
| 複製 | 選択して **複製** ボタン |
| 削除 | 選択して **削除** ボタン、または Delete キー |

## 11. 表示設定

| 設定 | 説明 |
| ---- | ---- |
| **方眼グリッド** | 5mm 間隔の方眼を表示（25mm ごとに太線） |
| **吸着(スナップ)** | ドラッグ時に方眼へ吸着 |
| **配置ガイド** | ドラッグ中に整列位置を rose 色の破線で表示 |
| **余白ガイド** | 上下・外側・折り目の余白を amber 色の点線で表示（PDF には含まれない） |
| **ズーム** | `-` / `+` / **画面に合わせる** で拡大縮小 |

### 余白ガイドの調整

「余白ガイド」を ON にすると、右側に3つのスライダーが表示されます。

| スライダー | 調整範囲 | 内容 |
|-----------|---------|------|
| **上下** | 5〜25mm | 用紙上下の余白 |
| **外側** | 5〜20mm | 用紙左端・右端からの余白 |
| **折り目** | 5〜20mm | 中央折り目内側からの余白 |

## 12. プロパティパネル（既存ブロックの編集）

枠を選択して **プロパティ** を押すと、右側にサイドパネルが開きます。

### 大問ブロック（question-block）

- 大問番号、観点区分（指示文）、配点
- **大問の横幅**（スライダーまたは px 直接入力、200〜1200px）
- 解答枠パターン、行数・列数・高さ、カンマ設定など

### 考査見出し枠（exam-header）

- 見出し文字列、枠の幅、枠の高さ

### 年組氏名欄（namebox）

- 第1〜4欄のラベル（年・組・番・氏名）、枠の幅、枠の高さ

### 観点別得点枠（score-table）

- 各列の観点区分名（知・技 等）と配点注記（/50 等）、枠の幅、枠の高さ

数値変更は即時反映、テキスト入力は入力後に自動反映されます。

## 13. 大問ブロックの4パターン（新規作成モーダル）

**大問を作成・追加** から新規作成する際に **解答枠パターン** を選びます。

### (1)(2) 小問複合枠

- **行数** / **列数** / **1行の高さ**
- **小問記号**（カンマ区切り）: `(1), (2), (3)` 等
- 行ごとのラベル形式（丸数字、カタカナ、英字、数字、手動入力）
- **「,」で区切る**: 各セル右端付近にカンマを表示
- 「マス数分 (1)〜(N) を自動生成」ボタンあり

### 等分割グリッド

- **行数** / **列数** / **1行の高さ**
- ラベルなしの空マス目

### 丸数字区分（既存データ）

新規作成では小問複合枠のラベル形式「丸数字」を使用します。
過去に作成した丸数字区分データは引き続き読み込めます。

### 左右2分割枠

- **分割比率**: 50:50 / 30:70 / 70:30
- **枠の高さ**

### 共通項目

- **大問番号**、**観点区分**（例: ○・△・×）、**配点**（例: 各問1点/10点）
- **大問の横幅**（スライダーまたは px 入力）
- モーダル下部にリアルタイム **プレビュー** が表示されます

## 14. 問題文から自動インポート

1. **問題文から自動インポート** をクリック
2. 問題文を貼り付け（`(1)`, `①`, `[1]` 等の記号を自動検出）
3. 行数・列数・大問番号・観点区分を確認
4. 適用 → 小問複合枠の大問ブロックが canvas に追加されます

## 15. 観点記号の一括置換

ヘッダー右側の **観点記号の一括置換** から、全大問ブロックの観点区分文字列を一括で置換できます（例: `○・△・×` → `知識・技能`）。

## 16. 出力（機能B）

| ボタン | 出力 |
| ------ | ---- |
| **PDFに保存 → B4横 (原寸1枚) PDF** | B4横1ページ PDF |
| **PDFに保存 → A4分割 (左面・右面2ページ) PDF** | A4縦2ページ（canvas 左右分割） |
| **Word形式 (.docx) で保存** | Word 文書 |

方眼・配置ガイド・余白ガイド・選択枠は出力時に自動で除外されます。

## 17. その他

- **白紙に戻す**: canvas 上のすべてを削除（確認あり）
- レイアウトの **保存/読込機能はありません**。リロードすると初期状態に戻ります

---

## 18. エラーが表示された場合

### 機能A（CSV）

- ヘッダーに `問題番号` と `問題文` があるか
- 問題番号が数値か、問題文が空でないか
- レイアウト設定が `横 × 縦 >= 表示件数` を満たすか
- 解答用紙を編集反映したい場合、**解答用紙に同期** を実行したか

### 機能B（エディタ）

- PDF/Word 生成中にブラウザのダウンロードがブロックされていないか
- 出力に時間がかかる場合は、そのまま待つ（処理中トーストが表示されます）
