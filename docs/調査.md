## 使われていない状態変数
はい。調査結果として、現状のプロジェクトは「本来想定された役割」と「実際の実装」が一致していません。

結論：
- selectedBlock は実際に使われている
- editingBlock は現在、実質的に設定されていない
- そのため、現状の編集処理は selectedBlock とプロパティパネルが担当している
実際の処理は次の通りです。
selectedBlock は、キャンバス上でブロックを選択したときに設定されます。

一方、editingBlock は以下のように常に null に戻されており、大問オブジェクトをセットしている箇所がありません。

そのため、

    // 編集中のブロックを置換

    // 新規大問の配置
}
のうち、現状は基本的に else 側、つまり新規追加が実行されます。
また、QuestionEditModal には常に、

が渡されるため、現在は既存大問の編集モードではなく、新規作成モードとして開きます。
したがって、現状の役割はこうです。
state	現在の実態
selectedBlock	キャンバス上で選択中のブロック。実際の編集に使用
editingBlock	大問編集モーダル用として用意されたが、現在は対象が設定されていない


つまり、editingBlock は設計途中、または過去の実装の名残になっている可能性が高いです。
